# GPM v2.0.16

## English

### Server

- Handle ultra-long queries proactively during initial-reference alignment: ordinary sequences keep the native mapping path, while only queries longer than 268,435,455 bases use windowed processing. This avoids first running a whole batch into the minimap2 long-CIGAR assertion; minimap2 itself is not modified.
- Verify recovered coordinates, CIGAR and candidate evidence before publishing alignment results. Reuse verified completed groups on a matching resumed task instead of repeating finished mapping work; incomplete or incompatible results are not silently accepted.
- The long-query path supports Linux x86_64 with minimap2 2.31-r1302. Other platforms and versions are not advertised as validated long-query configurations. Ordinary mappings do not require the bundled native recovery helper.
- `update.sh` no longer asks for confirmation. `run.sh` and generated `run_all.sh` update tools before launching a fresh runtime, and migrate compatible unfinished workspaces without replacing input data or dependency environments. When network updates are unavailable, a verified installed tool package can repair its prepared workspace runtime locally. An older installed updater may still ask once during the first upgrade.
- Standardize the public GRT name as LGZ (Linking Inter-assembly Units for Genome Zipping), while retaining compatibility with existing internal data and command names.

### App

- Improve Assembly and local-view controls, compact scope menus and parameter wrapping. Final Path selections now correspond to the adopted source intervals, with better synchronization between phase tracks and navigation.
- Combine project information with the Overview preview, keep complete source contigs visible, and align preview sources with the displayed Final Path. Downloaded preview images include the full preview rather than only the visible viewport.
- Make tooltips consistent, match their colors to the represented objects, and improve wrapping and unit placement. Align bilingual interface terminology and use the public LGZ name.
- Exclude unavailable MAPQ values from split-confidence calculations instead of treating them as strong alignment evidence.
- Check for App updates shortly after startup without blocking initial startup.

### Downloads

- Windows: x64 (`win-x86`) and ARM64 installers.
- macOS: Intel and Apple Silicon (ARM64) installers.
- Linux Server: `GPM_Server_2.0.16_source.tar.gz`.
- Test data: `test_data.zip`, carried forward unchanged from v2.0.15; originally published with v2.0.10.
- In-app upgrades are available through the CGAT docs update feed. Users on v2.0.12 or earlier must first manually install an updater-enabled version.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

- 初始参考比对主动识别超长 query：普通序列保持原生比对路径，仅长度超过 268,435,455 bp 的 query 进行分窗处理，不再先让整个批次撞上 minimap2 的超长 CIGAR 断言；不修改 minimap2 本身。
- 恢复结果须通过坐标、CIGAR 和候选证据校验后才发布。同一任务续跑时复用校验通过的已完成分组，避免重复比对；不静默接受不完整或不兼容的结果。
- 超长处理路径支持 Linux x86_64 和 minimap2 2.31-r1302，不将其他平台或版本宣称为已验证的超长配置；普通比对不依赖随包提供的原生恢复辅助程序。
- `update.sh` 不再询问确认；`run.sh` 和生成的 `run_all.sh` 在启动新运行时之前更新工具，并迁移兼容的未完成工作区，不替换输入数据或依赖环境。网络更新不可用时，可使用已校验的安装目录工具包在本地修复工作区运行时。首次升级时，旧版更新器仍可能询问一次。
- 对外统一将 GRT 称为 LGZ（Linking Inter-assembly Units for Genome Zipping），同时保留既有内部数据及命令名称的兼容性。

### App

- 改进装配主视图与局部视图的控制项、紧凑范围菜单和参数换行；Final Path 选中状态对应实际采用的来源区间，并改善分相轨道与导航同步。
- 整合项目信息与概览预览，完整保留来源 contig 的显示，并使预览来源与当前 Final Path 一致；下载预览图片时包含完整内容，而不只是当前可见区域。
- 统一提示框样式，使颜色与对应对象一致，改善文字换行与单位排版；统一双语界面术语，并使用对外名称 LGZ。
- 拆分置信度计算排除不可用的 MAPQ，不再将其当作强比对证据。
- App 启动后稍后检查更新，不阻塞初始启动。

### macOS 首次启动

以下提示同时适用于 Intel 和 Apple Silicon（ARM64）版本。

macOS App 使用 ad-hoc 签名，但未经 Apple 公证。请先将 `GPM.app` 拖入 `/Applications` 再打开。如果 macOS 阻止首次启动，请进入 **系统设置 -> 隐私与安全性** 并选择 **仍要打开**。如果该控件不可用，仅对从本项目官方 Release 下载的 App 执行：

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```
