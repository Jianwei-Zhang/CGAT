## English

### Server

- Build q0 paths from content-bound alignment evidence and source intervals across assemblies instead of choosing the first dataset as the starting assembly. Preserve donor provenance and require supporting evidence for structural edits; reports explain the accepted sources and resulting paths.
- Use a numbered q0–q3 LGZ pipeline without redundant identity stages. New delivery packages carry the updated stage and frozen-source provenance contracts; historical packages retain their original numbering when opened in App.
- For new workspaces, accept typed `--hifi` and `--ont` inputs and run the bundled DEGAP2.0 gap filler after LGZ for remaining internal N gaps. The extra `data/degap/post_lgz.fa` does not replace q3 or App Final Path. These inputs do not enable reads-based q0 quality exclusion or donor ranking. Legacy `--reads`, `--reads-type` and `--reads-qc` flags are rejected for new preparations; existing workspaces retain their saved recipes, and updating tools does not insert new stages into old runs.
- Reduce repeated hashing and checkpoint scans when resuming verified work, and process N runs and wrapped FASTA in native blocks. Content and output integrity checks remain enforced.

### App

- Import and validate the evidence-guided q0 packages while preserving frozen source provenance, including when datasets are added later.
- Link source highlighting across Main View, open Local Views and Final Path. Hover previews a match; click keeps it highlighted; Shift-click adds or removes matches. Final Path highlights only the adopted source overlap, respecting Local fragment ranges and orientation. Ctrl/Cmd comparison shortcuts and box selection keep their existing roles; Escape clears both linked highlights and editing selections.
- Refresh the project library with search, inline rename and drag interactions; organize settings into categorized sidebar panels.
- Clarify Project/Assembly navigation, left-align the scope selectors, and unify Main/Local toolbars with bounded spacing, wrapping controls and content-sized parameter fields. Keep folded preview-card feedback while reducing emphasis on expanded cards.
- Isolate macOS Local windows and offer an explicit close-without-saving action when saving fails. Existing workspace schema remains 8; back up workspaces before upgrading from older versions.

### Downloads

- Windows: x64 (`win-x86`) and ARM64 installers.
- macOS: Intel and Apple Silicon (ARM64) installers.
- Linux Server: `GPM_Server_2.0.21_source.tar.gz`.
- Test data: `test_data.zip`, preserved byte-for-byte from v2.0.20 and originally published with v2.0.10.
- Signed in-app updates are delivered through the CGAT docs update source. Users on v2.0.12 or earlier must first manually install a version that supports in-app updates.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

- 根据多组装的内容绑定比对证据与来源区间构建 q0 路径，不再直接以第一个数据集作为起始组装。保留供体来源，结构编辑须有证据支持；报告说明已采用来源及生成的路径。
- 使用编号清晰的 q0–q3 LGZ 流程，移除冗余恒等阶段。新交付包携带更新后的阶段与冻结来源约定；历史包在 App 中仍保留原编号。
- 新工作区使用分类型的 `--hifi`、`--ont` 输入，在 LGZ 完成后调用内置 DEGAP2.0，对剩余内部 N 缺口补洞。额外生成的 `data/degap/post_lgz.fa` 不替换 q3 或 App Final Path。这些输入不启用基于 reads 的 q0 质量排除或供体排序。新准备任务拒绝旧 `--reads`、`--reads-type`、`--reads-qc` 参数；已有工作区继续使用保存的配置，更新工具不会给旧运行插入新阶段。
- 续跑时减少已验证结果的重复哈希与检查点扫描，以原生块处理 N 区间和折行 FASTA。仍保留内容及输出完整性检查。

### App

- 支持导入并验证证据引导的 q0 交付包；后续添加数据集时仍保留冻结的来源信息。
- 主视图、已打开的局部视图与 Final Path 双向联动来源高亮。悬停临时预览，点击固定，Shift 点击追加或取消；Final Path 只高亮实际采用的交集，并考虑局部片段范围与方向。Ctrl/Cmd 比较快捷操作和框选保持原有用途；Esc 同时清除联动高亮与编辑选区。
- 更新项目库界面，加入搜索、行内重命名和拖动交互；设置页改为分类侧栏。
- 明确项目/组装导航，顶部范围选择框左对齐；统一主视图与局部视图工具栏，使用有上限的间距、可换行控件及随内容伸缩的参数框。保留折叠预览卡片的反馈，减弱展开卡片的高亮。
- 隔离 macOS 局部窗口；保存失败时提供明确的不保存关闭操作。工作区 schema 仍为 8；从旧版本升级前请备份。
