# GPM v2.0.14

## English

### Server

- No functional Server changes are included in this App release. The matching Server source package is refreshed for v2.0.14 and retains the docs-first tool and runtime updater introduced with v2.0.13.

### App

- New installations now default to unlimited Main and Local edit history. **Restore defaults** also selects unlimited history.
- Existing saved step limits are preserved. Users who previously selected 50, 100, 200 or a custom limit can keep that setting, or choose **Unlimited** explicitly.
- In-app updates continue to use the CGAT docs update feed. The GitHub Release contains only manual installers, Server source and example data.

Users on v2.0.13 can check **Settings → App updates** and upgrade in the app. Upgrading from v2.0.12 or earlier still requires one manual installation of a signed updater-enabled release.

### Downloads

- Windows: x64 (`win-x86`) and ARM64 installers.
- macOS: Intel and Apple Silicon (ARM64) installers.
- Linux Server: `GPM_Server_2.0.14_source.tar.gz`.
- Test data: `test_data.zip`, carried forward unchanged from v2.0.13 (originally published with v2.0.10).

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

- 本次 App 发布不包含 Server 功能变更。配套 Server 源码包已同步刷新到 v2.0.14，并保留 v2.0.13 引入的 docs 优先工具与运行库更新流程。

### App

- 新安装默认使用不限步数的 Main 和 Local 编辑历史；**恢复默认设置**也会选择不限步数。
- 已保存的具体容量不会被覆盖。此前选择 50、100、200 步或自定义值的用户可继续使用原设置，也可主动选择 **不限步数**。
- 应用内更新继续使用 CGAT docs 更新源。GitHub Release 只保留手动安装包、Server 源码和示例数据。

v2.0.13 用户可在 **设置 → 应用更新** 中检查并直接升级。从 v2.0.12 或更早版本升级时，仍需手动安装一次带签名更新功能的正式版本。

### 下载

- Windows：x64（`win-x86`）和 ARM64 安装包。
- macOS：Intel 和 Apple Silicon（ARM64）安装包。
- Linux Server：`GPM_Server_2.0.14_source.tar.gz`。
- 测试数据：`test_data.zip`，从 v2.0.13 原样保留，最初随 v2.0.10 发布。

### macOS 首次启动

以下提示同时适用于 Intel 和 Apple Silicon（ARM64）版本。

macOS App 使用 ad-hoc 签名，但未经 Apple 公证。请先将 `GPM.app` 拖入 `/Applications` 再打开。如果 macOS 阻止首次启动，请进入 **系统设置 -> 隐私与安全性** 并选择 **仍要打开**。如果该控件不可用，仅对从本项目官方 Release 下载的 App 执行：

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```
