# GPM v2.0.15

## English

### Server

- Record minimap2 tool identity and input-length risk information for each run, and explain CIGAR span assertions without assuming an out-of-memory failure or a confirmed cause.
- Preserve separate logs and partial outputs for repeated failed GRT alignments, rather than overwriting an earlier attempt in the same process.
- Minimap2 binaries and alignment defaults are unchanged. This improves diagnosis and evidence retention; it does not claim to fix minimap2's long-CIGAR limitation. Cross-GAP repair safeguards and docs-first tools/runtime updates are retained.

### App

This Server-source refresh leaves the published App installers unchanged. The existing App changes remain:

- Settings dropdowns now use the same control and option styling as the header language picker, including light/dark themes, selection and keyboard focus.
- History capacity keeps its presets and custom input, with matching dropdown styling. Existing settings and history limits are preserved.
- Fixed an error in the settings save feedback.
- Simplified the project-library header and validation labels (**Projects** / **Validate**, Chinese **校验**). Validation is right-aligned when there are no failed projects; failed-project actions stay on the same row. Validation preserves focus and the current project detail.
- Final Path now refreshes immediately after Main View contig splits, split undo and synchronized Local-to-Main edits. Main View undo/redo/reset also refreshes the affected panels without reopening the Assembly page.

### Downloads

- Same-version installer refresh from `fb6acdc` (workflow `40485534463`). If you already installed v2.0.15, download and reinstall the refreshed installer to receive this fix.
- Windows: x64 (`win-x86`) and ARM64 installers.
- macOS: Intel and Apple Silicon (ARM64) installers.
- Linux Server: `GPM_Server_2.0.15_source.tar.gz`.
- Test data: `test_data.zip`, carried forward unchanged from v2.0.14 (originally published with v2.0.10).
- In-app updates are available through the CGAT docs feed. Users on v2.0.12 or earlier still need one manual installation of an updater-enabled version.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

- 每次运行记录 minimap2 工具身份和输入长度风险信息，明确提示 CIGAR 区间长度断言，不直接将其归因为内存不足或认定具体根因。
- GRT 同一进程的多次比对失败分别保留日志和部分输出，不再覆盖之前的失败证据。
- 不修改 minimap2 二进制或默认比对参数。本次改进诊断和证据保留，不宣称已解决 minimap2 的超长 CIGAR 限制；保留跨 GAP 修复保护和 docs 优先的工具/运行库更新流程。

### App

本次 Server 源码刷新不改动已发布的 App 安装包，已有 App 变更保留如下：

- 设置面板下拉框统一使用顶部语言切换的控件及选项样式，包括明暗主题、选中状态和键盘焦点。
- 回溯容量保留预设选项和自定义输入，并采用一致的下拉样式；不改动已有设置和历史容量。
- 修复设置保存反馈中的错误。
- 项目库标题及校验按钮精简为英文 **Projects** / **Validate**、中文 **校验**；没有失败记录时校验按钮右对齐，出现“删除失败”操作时仍保持同排，校验期间保留焦点和当前项目详情。
- 修复主视图分割、撤销分割及局部同步主视图操作后 Final Path 未及时刷新的问题；主视图撤销、重做和重置也会刷新相关面板，无需重新进入装配页。
