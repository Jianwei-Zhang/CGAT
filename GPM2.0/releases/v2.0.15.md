# GPM v2.0.15

## English

### Server

- Initial-reference `asm10` alignment now checks query lengths before mapping: ordinary sequences keep the native path, while ultra-long sequences use overlapping windows and checked original-coordinate reconstruction. No whole-batch crash/retry or user-written splitting configuration is required; minimap2 itself is unchanged.
- Reuse verified completed query groups after interruption instead of rerunning ordinary sequences. Partial, changed or ambiguous recovery evidence is not published, and unknown mapping confidence is never substituted for a checked result.
- `update.sh` backs up and updates without a Y/N prompt. New `run.sh` and generated `run_all.sh` launchers check updates before analysis and reload updated code. Prepared runtimes can first synchronize from the verified local installation, including on offline compute nodes; failed writes stop startup. Recognized older launchers are upgraded with rollback backups; customized files remain protected.
- Long-query reconstruction currently supports minimap2 `2.31-r1302` on Linux x86_64 with the bundled glibc 2.17-compatible companion. Ordinary queries do not need the companion. Supported stopped workspaces can resume through the existing commands; retain original inputs and failure logs. Local synthetic validation is not a claim of validation on the customer's unavailable complete wheat assembly.
- Retain minimap2 identity/length diagnostics, per-attempt failure evidence and cross-GAP repair safeguards.

### App

This Server-source refresh leaves the published App installers unchanged. The existing App changes remain:

- Settings dropdowns now use the same control and option styling as the header language picker, including light/dark themes, selection and keyboard focus.
- History capacity keeps its presets and custom input, with matching dropdown styling. Existing settings and history limits are preserved.
- Fixed an error in the settings save feedback.
- Simplified the project-library header and validation labels (**Projects** / **Validate**, Chinese **校验**). Validation is right-aligned when there are no failed projects; failed-project actions stay on the same row. Validation preserves focus and the current project detail.
- Final Path now refreshes immediately after Main View contig splits, split undo and synchronized Local-to-Main edits. Main View undo/redo/reset also refreshes the affected panels without reopening the Assembly page.

### Downloads

- Windows: x64 (`win-x86`) and ARM64 installers.
- macOS: Intel and Apple Silicon (ARM64) installers.
- Linux Server: `GPM_Server_2.0.15_source.tar.gz`.
- Test data: `test_data.zip`, carried forward unchanged from v2.0.14 (originally published with v2.0.10).
- In-app updates are available through the CGAT docs feed. Users on v2.0.12 or earlier still need one manual installation of an updater-enabled version.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

- 初始参考 `asm10` 比对在启动前检查 query 长度：普通序列仍走原生路径，只有超长序列进入重叠分窗和经核验的原坐标恢复。不先让整批任务崩溃再补救，不要求用户手动拆分或编写配置，也不修改 minimap2 本体。
- 中断后复用证据核验通过的已完成分组，避免重跑普通序列；部分、已变化或有歧义的恢复结果不发布，不用未知置信度替代核验结果。
- `update.sh` 备份后直接更新，不再询问 Y/N。新版 `run.sh` 和新生成的 `run_all.sh` 在分析前检查更新并重新加载代码；工作区运行库可先从校验通过的本地安装同步，离线计算节点也无需另行下载；写入失败则停止。可识别的旧入口备份后升级，自定义文件保持保护。
- 长序列恢复目前支持 Linux x86_64 上的 minimap2 `2.31-r1302`，使用包内兼容 glibc 2.17 的辅助程序；普通序列不需要该程序。支持的已停止工作区可通过原命令恢复，请保留原输入和失败日志。本地合成验证不代表已验收尚未提供的客户完整小麦数据。
- 保留 minimap2 工具身份/长度诊断、各次失败证据及跨 GAP 修复保护。

### App

本次 Server 源码刷新不改动已发布的 App 安装包，已有 App 变更保留如下：

- 设置面板下拉框统一使用顶部语言切换的控件及选项样式，包括明暗主题、选中状态和键盘焦点。
- 回溯容量保留预设选项和自定义输入，并采用一致的下拉样式；不改动已有设置和历史容量。
- 修复设置保存反馈中的错误。
- 项目库标题及校验按钮精简为英文 **Projects** / **Validate**、中文 **校验**；没有失败记录时校验按钮右对齐，出现“删除失败”操作时仍保持同排，校验期间保留焦点和当前项目详情。
- 修复主视图分割、撤销分割及局部同步主视图操作后 Final Path 未及时刷新的问题；主视图撤销、重做和重置也会刷新相关面板，无需重新进入装配页。
