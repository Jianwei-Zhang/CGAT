## Updates since v2.0.9

- Add a chromosome Preview page between Projects and Assembly to show how source-dataset contigs contribute to each Final Path. Aligned source tracks, visible gap markers, whole-card provenance highlighting, and one-click Assembly navigation make the overview easier to follow.
- Cache Preview models in memory and in the project workspace for faster repeat visits and reopening. Relevant edits invalidate the cache, affected chromosomes can be rebuilt independently, and unsaved Final Path edits remain protected.
- Improve Assembly and local-view navigation with full-range overview on first entry/reopening, independent viewport controls, reliable narrow-window dragging, hand-mode wheel zoom, and automatic ruler spacing. Preserve remaining local-view layout when contigs are removed.
- Support drag-and-drop entry for delivery archives, extracted deliveries, and existing workspaces, with consistent workspace identity handling.
- Simplify project validation controls, fix long-path error notifications, unify page spacing and card styling, hide clipped contig names completely, and keep short Final Path contigs and gaps visible in Preview and Project Export.
- Installers are provided for Windows x64 (`win-x86`) and ARM64 and macOS Intel and Apple Silicon.

### macOS first launch

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 相对 v2.0.9 的更新

- 在项目页和装配页之间新增染色体预览页，展示各来源 ds 的 contig 如何组成 Final Path。支持来源轨道对齐、Gap 标注、整卡片悬停高亮来源区段，并可直接进入对应染色体的装配页。
- 为预览增加会话内缓存和项目工作区持久化缓存，减少重复进入和重新打开项目时的读取与构建。相关编辑自动使缓存失效，可按受影响染色体增量重建，同时保护未保存的 Final Path 编辑。
- 优化装配与局部视图导航：首次进入或重新打开时展示完整总览，提供独立视口控制、可靠的小窗口拖动、手形模式滚轮缩放和自动刻度间距；删除 contig 后保留其他局部视图的布局。
- 支持拖放交付压缩包、解压后的交付目录及已有工作区进入项目，并统一工作区路径识别。
- 简化项目校验按钮，修复长路径错误提示，统一页面边界与卡片样式；名称放不下时完整隐藏，并确保预览及项目导出中的短 Final Path 片段和 Gap 可见。
- 提供 Windows x64（`win-x86`）/ARM64 以及 macOS Intel/Apple Silicon 安装包。

### macOS 首次启动

macOS App 使用 ad-hoc 签名，但未经 Apple 公证。请先将 `GPM.app` 拖入 `/Applications` 再打开。如果 macOS 阻止首次启动，请进入 **系统设置 -> 隐私与安全性** 并选择 **仍要打开**。如果该控件不可用，仅对从本项目官方 Release 下载的 App 执行：

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```
