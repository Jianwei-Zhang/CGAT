# GPM v2.0.10

## English

### Server

#### Improvements
- Prepare Linux Server from a standalone source package, with the official `gpm-server` skill and safer update staging (October 13–15).
- Run chromosome-local and batched alignment work more efficiently, with independent checkpoints and shared-cache reuse (October 17). Step2 gap-screen remains experimental and disabled by default.
- Keep reports smaller with compact audit-table previews and exact totals (October 18); complete audit records and biological results remain in the workspace.

These Server-source updates do not rebuild the App installers or change the example data.

### App

#### New features
- Inspect chromosome-level Final Path composition in Preview, highlight source contigs, and jump directly into Assembly.
- Import archives and extracted results, or open existing workspaces, using drag and drop.

#### Improvements and fixes
- Reopen Preview faster with workspace caching while protecting unsaved path edits.
- Navigate Assembly and local views more smoothly, with preserved viewports, clearer gap markers and readable short contigs.
- Simplify project validation and fix long-path notifications and clipped labels. Update build dependencies to address known parsing and denial-of-service vulnerabilities.

### Downloads

Windows x64 (`win-x86`) / ARM64; macOS Intel / Apple Silicon (ARM64). Linux Server source: `GPM_Server_2.0.10_source.tar.gz`.

Includes `test_data.zip`.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

#### 改进
- 提供独立 Linux Server 源码包，包含官方 `gpm-server` skill 和安全的更新暂存流程（10 月 13–15 日）。
- 优化染色体局部调度和批量比对，保留独立检查点并复用共享缓存（10 月 17 日）。Step2 gap-screen 仍属实验功能，默认关闭。
- 报告采用精简审计表预览并保留准确总数，减少体积（10 月 18 日）；完整审计记录及生物学结果保留在工作区。

以上 Server 源码更新未重建 App 安装包，也未改变示例数据。

### App

#### 新功能
- 新增染色体 Preview，查看 Final Path 的来源组成、高亮来源 contig，并直接跳转 Assembly。
- 支持拖放导入压缩包、解压结果及打开已有工作区。

#### 改进与修复
- 通过工作区缓存加快 Preview 再次打开，同时保护未保存的路径编辑。
- 改善 Assembly 与局部视图导航，保留视口，清晰显示 Gap 和短 contig。
- 简化项目校验，修复长路径通知及截断标签；更新构建依赖，修复已知的解析与拒绝服务漏洞。

### 下载

提供 Windows x64（`win-x86`）/ARM64、macOS Intel/Apple Silicon（ARM64）安装包，以及 Linux Server 源码 `GPM_Server_2.0.10_source.tar.gz`。

包含示例数据 `test_data.zip`。

### macOS 首次启动
以下提示同时适用于 Intel 和 Apple Silicon（ARM64）版本。

macOS App 使用 ad-hoc 签名，但未经 Apple 公证。请先将 `GPM.app` 拖入 `/Applications` 再打开。如果 macOS 阻止首次启动，请进入 **系统设置 -> 隐私与安全性** 并选择 **仍要打开**。如果该控件不可用，仅对从本项目官方 Release 下载的 App 执行：

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```
