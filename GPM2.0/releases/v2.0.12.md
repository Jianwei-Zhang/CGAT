# GPM v2.0.12

## English

### Server

#### Fixes
- Preserve exact fragment provenance when gap filling trims earlier patches or refill results, so q3-to-q4 finalization remains reliable without relaxing sequence validation (October 24).
- Keep mixed-direction and retained-fragment evidence consistent with Final Path, and extend the coordinated tools/workspace updater to the affected display and packaging entrypoints (October 26).

#### Improvements
- Add compact progress logs, optional terminal colors and a read-only log viewer (October 26). Full diagnostics remain available; scheduler logs stay plain by default.
- Check and update Server tools, the official skill and the current project runtime with one interactive `update.sh`. Preserve local skill experience and analysis data, with backed-up updates and rollback.
- Prefer the official docs download mirror, falling back to GitHub Release on failure. New tool installations default to `~/bin/GPM_Server`, while existing and custom locations remain supported.

These post-release Server-source updates leave the App installers and `test_data.zip` unchanged. The App changes below are those shipped with v2.0.12, not later source-only changes.

### App

#### New features
- Split contigs non-destructively at evidence-guided reference boundaries, preview the split, and undo from either adjacent fragment.
- Inspect alignments across chromosomes, add contigs to another chromosome, and record the addition in the destination history.

#### Improvements
- Use consistent role colors, system-aware light/dark themes, clearer alignment hints and unified floating menus; reveal project locations from the project library.
- Prepare Preview after successful imports, improve source-anchor placement and reference visibility, and preserve Assembly viewport/scroll state during navigation.

### Downloads

Windows x64 (`win-x86`) / ARM64; macOS Intel / Apple Silicon (ARM64). Linux Server source: `GPM_Server_2.0.12_source.tar.gz`.

Carries forward the existing `test_data.zip` unchanged from v2.0.10.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

#### 修复
- 补洞裁剪已有补片或前轮补洞结果时，精确保留片段来源，提高 q3 到 q4 最终路径生成的可靠性，不放宽序列校验（10 月 24 日）。
- 使混合方向及保留片段的证据显示与 Final Path 一致，并扩展工具/工作区统一更新器，覆盖相关显示和封包入口（10 月 26 日）。

#### 改进
- 新增精简进度日志、可选终端颜色及只读日志查看器（10 月 26 日）；保留完整诊断，调度日志默认保持纯文本。
- 通过同一个交互式 `update.sh` 检查并更新 Server tools、官方 skill 和当前项目运行库，保留 skill 本地经验与分析数据，支持备份和回滚。
- 下载优先使用官网镜像，失败时回退 GitHub Release；新安装默认放在 `~/bin/GPM_Server`，继续支持已有安装路径和自定义位置。

以上发布后的 Server 源码更新未改变 App 安装包及 `test_data.zip`。下方 App 变化是 v2.0.12 已发布安装包的内容，不包含后续仅修改源码的变化。

### App

#### 新功能
- 在证据引导的参考边界非破坏性拆分 contig，预览拆分结果，并从任一相邻片段撤销。
- 支持跨染色体查看比对、添加 contig，并在目标染色体历史中记录操作。

#### 改进
- 统一角色配色、跟随系统的明暗主题、比对提示及浮动菜单；可从项目库打开项目所在位置。
- 成功导入后准备 Preview，改善来源锚点定位和参考可见性，并在导航时保留 Assembly 视口与滚动位置。

以下提示同时适用于 Intel 和 Apple Silicon（ARM64）版本。
