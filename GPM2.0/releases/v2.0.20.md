## English

### Server

- Fix result-policy generation and DEGAP candidate export on Python 3.10. SHA-256 checks now use bounded streaming reads without requiring a newer Python API; verified completed alignments remain reusable after updating the tools and prepared workspace.
- Support a verified ARM-to-x86 continuation for the reviewed minimap2 2.31 build pair, after calibration is complete and before long-query processing has started. Completed alignments keep their original provenance; unfinished work uses the new executable against the original index. Existing input, output and quality checks still apply; this is not general compatibility with arbitrary binaries or versions.
- The November 18 Server source update fixes large-assembly runs rejected solely because routing or resume metadata exceeded a fixed size limit. Metadata is read incrementally while input identity, result integrity and publication checks remain enforced. After updating the tools and prepared workspace, resume the existing run to reuse verified completed work.
- Automatically calibrate eligible large-reference alignment tasks on a bounded set of complete contigs. Faster filtering is enabled only after repeated timing and coverage/assignment checks using the project's actual score threshold; explicit user filtering settings are preserved. This allows limited output differences rather than promising equivalence to default minimap2 output or a whole-assembly speedup.
- Route exceptionally long queries on large references through bounded native windows with original-coordinate reconstruction and whole-record risk checks. Ordinary contigs remain intact. This native-window path supports ARM without the x86 companion required by the legacy recovery route.
- Reuse verified completed alignment work on resume. Preserve paid default results, review only selected risky records, and return remaining work to default filtering when the review budget is exhausted, without restarting the whole assembly.
- Audit large PAF files with exact disk-backed statistics rather than loading all intervals into memory or rejecting otherwise valid large outputs. Full and light delivery packages retain output-bound alignment policy and source parameters; unavailable MAPQ is no longer treated as high confidence.
- Ship the pinned DEGAP2.0 runtime in the shared `cgat-server` environment, with task-linked candidate export for the new App workflow. For older installations, update dependencies with the new installer before updating tools and prepared workspaces; preserve existing projects and results.

### App

The November 18 maintenance update changes only the Server source archive; the published App installers are unchanged.

- Organize projects into nested library partitions, navigate from partition to project to chromosome, and remove partitions without deleting project files.
- Use DEGAP2.0 task cards to export gap-extension jobs and import their linked results as candidates. Imports check their originating project and task; they do not automatically replace Final Path.
- Export the current Final Paths as AGP, retaining component ranges, orientation and explicit gaps.
- View chromosome overviews inside project details, with persistent provenance outlines and more compact, stable preview layouts. Refresh Local View evidence after context-menu additions and clarify overlapping evidence.
- Use Ctrl+wheel to zoom assembly views while ordinary scrolling remains available. Compact navigation controls and content-sized menus, and dock new Local Views for easier navigation.
- Check for updates once immediately at startup rather than waiting for the initial timer. Existing workspace schema remains 8; back up workspaces before upgrading from older releases.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

- 修复 Python 3.10 环境下生成结果策略记录及导出 DEGAP 候选时的兼容性问题。SHA-256 校验改用有界分块读取，不再依赖较新 Python 版本的接口；更新工具和已准备的工作区后，仍可复用校验有效的已完成比对。
- 对已审核的 minimap2 2.31 ARM/x86 构建组合，支持在校准完成、超长 query 尚未开始处理时跨架构续跑。已完成比对保留原始来源，未完成部分使用新执行程序和原索引；仍执行原有输入、结果与质量检查，不代表任意二进制或版本之间均可迁移。
- 11 月 18 日更新的 Server 源码修复了大型组装任务仅因路由或续跑元数据超过固定大小上限而失败的问题。元数据改为增量读取，仍保留输入身份、结果完整性及发布检查。更新工具和已准备的工作区后，可在原任务上续跑，复用校验有效的已完成结果。
- 对满足条件的大参考比对任务，内部自动选取有限的完整 contig 校准参数。重复测速及按项目实际 score 阈值进行的覆盖、归属检查通过后，才采用更快的过滤设置；用户显式指定的过滤参数保持不变。允许有限输出差异，不承诺与默认 minimap2 结果等价，也不据此保证整个组装的加速倍数。
- 大参考上的超长 query 自动采用有界原生分窗，恢复原坐标后检查整条记录的风险；普通 contig 保持完整。该原生分窗路径支持 ARM，不依赖旧恢复路径所需的 x86 辅助程序。
- 续跑复用校验有效的已完成比对，保留已有默认结果，只对筛出的风险记录进行有限复核。复核预算用完后，剩余工作转回默认过滤，不重跑整个组装。
- 大型 PAF 改用磁盘支持的精确统计，避免将全部区间装入内存，也不再仅因输出较大而拒绝有效结果。完整包和轻量包保留与输出绑定的比对策略、实际源参数；不再把不可用的 MAPQ 当作高置信度。
- 在共用的 `cgat-server` 环境中附带固定版本的 DEGAP2.0，支持与新 App 工作流配套的任务关联候选导出。旧安装需先用新安装器补齐依赖，再更新工具和已准备的工作区；保留原有项目及结果。

### App

11 月 18 日维护更新仅替换 Server 源码包，已发布的 App 安装包保持不变。

- 项目库支持嵌套分区，可按分区、项目、染色体逐级导航；删除分区不会删除项目文件。
- 通过 DEGAP2.0 任务卡导出补洞延伸任务，将关联结果导入为候选。导入时校验原项目和任务，不会自动替换 Final Path。
- 将当前 Final Path 导出为 AGP，保留来源片段范围、方向和显式 gap。
- 项目详情内展示染色体概览，持续保留来源轮廓，精简预览布局并稳定宽度；通过右键菜单添加来源后刷新 Local View 证据，改善重叠证据说明。
- 装配视图使用 Ctrl+滚轮缩放，保留普通滚动。精简导航控件，菜单宽度适应内容，新建 Local View 默认停靠，便于切换。
- 启动后立即检查一次更新，不再等待首次定时器。现有工作区 schema 仍为 8；从旧版本升级前请备份工作区。
