## English

### Server

- Package the current Server runtime, including the improvements already available in the November 6 v2.0.17 source refresh; this is not a second mapping-algorithm change. Installation and tool-update commands now target v2.0.18.
- Retain resource-aware reference mapping and verified checkpoint reuse. New workspaces default to `-K 1G`; this is a query batch size, not a RAM cap. Existing workspaces keep their saved settings. The more aggressive `--minimap-filter 0.01` remains opt-in and can change alignments; use a new output directory when changing it.
- Include additive official/local telomere and centromere libraries plus run-only `--tel` / `--cen` inputs. Prepare freezes sequences, thresholds and provenance; resume keeps that snapshot, and tool updates preserve local library entries. Centromere annotations are candidate regions, not proof of a functional centromere or chromosome assignment.

### App

- Keep dense Local View dragging more responsive by reusing collinearity layers and moving expensive redraws off the interaction path. Preserve alignment geometry during full-range dragging and show render progress inside the plot.
- Link Final Path hover highlights to their Main View source segments, with clearer highlights in light and dark themes.
- Preserve telomere/centromere annotation provenance when importing Server delivery packages, while accepting older packages without provenance. Opening an existing workspace migrates schema 6 to 7; back up workspaces before upgrading, because older Apps cannot be assumed to reopen a migrated workspace.
- Clarify overview sections and chromosome previews, align Local View track names with Main View, improve English toolbar/title layout, and reveal project-row actions on hover. The native title now uses the full product name.

### Downloads

- Windows: x64 (`win-x86`) and ARM64 installers.
- macOS: Intel and Apple Silicon (ARM64) installers.
- Linux Server: `GPM_Server_2.0.18_source.tar.gz`.
- Test data: `test_data.zip`, preserved byte-for-byte from v2.0.17 and originally published with v2.0.10.
- Signed in-app updates are available through the CGAT docs update source. Users on v2.0.12 or earlier must first manually install a version that supports in-app updates.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

- 发布当前 Server 运行库，包含 11 月 6 日 v2.0.17 源码包刷新中已提供的改进；本次并非再次更改比对算法。安装和工具更新命令统一指向 v2.0.18。
- 保留资源适配参考比对和已核验检查点复用。新工作区默认 `-K 1G`，该参数控制 query 批大小，并非内存上限；已有工作区沿用保存的设置。更积极的 `--minimap-filter 0.01` 仍须显式开启，可能改变比对结果，更改时请使用新的输出目录。
- 包含叠加使用的官方、本地端粒及着丝粒库，以及仅本次生效的 `--tel` / `--cen` 参数。准备阶段冻结序列、阈值和来源，续跑沿用该快照，工具更新保留本地条目。着丝粒注释仅为候选区域，不代表功能着丝粒证明或染色体归属。

### App

- 复用共线性图层并将高开销重绘移出交互路径，改善密集 Local View 的拖动响应；全范围拖动时保留比对几何，渲染进度显示在图内。
- Final Path 悬停高亮联动至 Main View 对应来源片段，并加强明暗主题下的高亮可辨识度。
- 导入 Server 交付包时保留端粒、着丝粒注释来源，同时兼容不带来源的旧包。打开已有工作区时将 schema 6 迁移为 7；升级前请备份工作区，不能假定旧 App 可以重新打开迁移后的工作区。
- 明确概览分区与染色体预览，统一 Local View 与 Main View 的轨道名称，改善英文工具栏及标题布局，项目行操作在悬停时显示；原生窗口标题采用完整产品名。
