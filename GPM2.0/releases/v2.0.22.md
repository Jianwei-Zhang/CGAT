## English

### Server

- Run DEGAP2.0, TGS-GapCloser, quarTeT or LR_Gapcloser against the same LGZ assembly. With typed reads, DEGAP2.0 is the default; without reads, the LGZ baseline stands on its own. A native tool’s “filled” flag is not enough: CGAT checks the source sequence and boundaries, and retains the original gap if a proposal closes it only partially.
- Use `refine.py` to run App-exported gap or telomere tasks. A project snapshot keeps edits on other chromosomes intact. Completed numbered workspaces can append reads without rerunning verified LGZ work; older workspaces have a separate, explicit migration path.
- Open `06_report/report.html` and follow sections 01–08 from the inputs and Q0 placements to structural repairs, chromosome ends, per-gap tool outcomes and the delivered Final Paths. Regenerate a detached report offline without repeating the analysis. The bundled DEGAP2.0 native report opens directly; reports start in English with a light theme.
- Q0 can retain a continuous source contig across reverse reference anchors. Local flanking anchors distinguish duplicates at different loci, and competing paths cannot count the same source interval twice. Reuse a verified selection from the same evidence generation instead of selecting the path again.

### App

- Compare automatic tools and manual batches in one project. Inspect the candidates for each gap and adopt a repair without replacing unrelated edits. Export manual tasks with the project-wide Final Path snapshot, then import the returned patch into that project.
- Export from the pseudomolecule preview. Choose an assembled FASTA or an AGP layout with its matching component FASTA; source-qualified component IDs distinguish sequences with the same name.
- Collapse the project sidebar and switch projects from its flyout. Set track and strip colors in Settings; the native title bar follows the App theme. On macOS, each Local View routes commands through its own window.

### Downloads

- Windows: x64 (`win-x86`) and ARM64 installers.
- macOS: Intel and Apple Silicon (ARM64) installers.
- Linux Server: `GPM_Server_2.0.22_source.tar.gz`.
- Test data: `test_data.zip`, preserved byte-for-byte from v2.0.21 and originally published with v2.0.10.
- Signed in-app updates are delivered through the CGAT docs update source. Users on v2.0.12 or earlier must first manually install a version that supports in-app updates.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

- 从同一份 LGZ 组装分别运行 DEGAP2.0、TGS-GapCloser、quarTeT 或 LR_Gapcloser。有分类型 reads 时默认用 DEGAP2.0，没有 reads 时单独交付 LGZ 基线。工具标记“已填补”不等于采纳：CGAT 核查来源序列与边界，只部分闭合的提案保留在诊断中，交付序列保留原缺口。
- 用 `refine.py` 运行 App 导出的缺口或端粒任务。项目快照保留其他染色体的编辑。已完成的编号工作区可以追加 reads，不重跑已验证的 LGZ 步骤；旧工作区另有显式迁移入口。
- 打开 `06_report/report.html`，按 01–08 节从输入和 Q0 定位，追溯结构修正、染色体端部、各工具的逐缺口结果和最终交付路径。可以离线重新生成独立报告，无需重跑分析。随包 DEGAP2.0 的原生报告可直接打开；报告默认英文、浅色。
- Q0 遇到参考反向锚点时可以保留连续的来源 contig。通过两侧局部锚点区分不同位点的重复片段，竞争路径不能重复计入同一来源区间。同一代证据已验证的选路结果可以复用，无需再选一次。

### App

- 在同一项目中比较自动工具和手动批次，逐缺口查看并采纳候选，不覆盖无关编辑。导出手动任务时携带全项目 Final Path 快照，返回的补丁导回原项目。
- 从伪分子预览统一导出组装 FASTA，或成对导出 AGP 布局与组件 FASTA；组件 ID 带来源信息，可区分同名序列。
- 项目侧栏可折叠，折叠后仍可在浮层中切换项目。在设置中自定义轨道与条带配色；原生标题栏跟随 App 主题。macOS 的每个局部视图通过自己的窗口发送命令。
