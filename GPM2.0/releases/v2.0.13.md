# GPM v2.0.13

## English

### Server

- Include the Server updates previously delivered in v2.0.12 source refreshes: compact progress logs with optional terminal colors, more reliable retained-fragment provenance and Final Path generation, and safer workspace-runtime updates.
- Use one interactive `update.sh` to check and update tools, the official skill and the current project runtime, preserving analysis data and local skill experience with backups and rollback.
- Prefer the official docs mirror with GitHub fallback. New tool installations default to `~/bin/GPM_Server`; existing and custom paths remain supported.

### App

- Add in-app update checks and signed downloads, with release notes in the selected language and an explicit install-and-restart action. Prefer the docs mirror and fall back to GitHub on failure; reminders can be postponed for 24 hours.
- Edit contig fragments in Main and Local views with separate histories. Keep anchors distinct from actual splits, preview cuts before splitting, and materialize Main splits as independent Local contigs.
- Improve explicit multi-contig movement, fragment recovery and deletion history; preserve the viewport and restore alignment evidence when returning to the Local view.
- Use clearer Auxiliary labels and compact Import / Open project actions.

Users upgrading from v2.0.12 or earlier must install this version manually once to enable future in-app updates. Updates are never installed automatically.

### Downloads

- Windows: x64 (`win-x86`) and ARM64 installers.
- macOS: Intel and Apple Silicon (ARM64) installers.
- Linux Server: `GPM_Server_2.0.13_source.tar.gz`.
- Test data: `test_data.zip`, carried forward unchanged from v2.0.12 (originally published with v2.0.10).

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

- 汇总此前通过 v2.0.12 源码刷新提供的 Server 更新：精简进度日志与可选终端颜色、更可靠的保留片段来源及 Final Path 生成，以及更安全的工作区运行库更新。
- 通过同一个交互式 `update.sh` 检查并更新工具、官方 skill 和当前项目运行库，保留分析数据与 skill 本地经验，支持备份和回滚。
- 优先使用官网文档镜像，失败时回退 GitHub；新安装默认放在 `~/bin/GPM_Server`，继续支持已有路径和自定义位置。

### App

- 新增应用内更新检查与签名下载，按当前语言显示更新说明，由用户确认后安装并重启。优先使用文档站镜像，失败时回退 GitHub；可暂停自动提醒 24 小时。
- 支持 Main 和 Local 视图中的 contig 片段编辑，分别保留历史。锚点与实际拆分保持独立，拆分前可预览切点，Main 拆分可在 Local 中呈现为独立 contig。
- 改善明确选中的多个 contig 移动、片段恢复与删除历史；保留视口位置，并在返回 Local 视图时恢复比对证据。
- 统一使用更清晰的辅助标签，精简项目的导入 / 打开操作。

从 v2.0.12 或更早版本升级时，需要先手动安装本版本一次，之后才能使用应用内更新。更新不会自动安装。

- macOS：Intel 和 Apple Silicon（ARM64）安装包。
- Linux Server：`GPM_Server_2.0.13_source.tar.gz`。
- 测试数据：`test_data.zip`，从 v2.0.12 原样保留，最初随 v2.0.10 发布。

### macOS 首次启动

以下提示同时适用于 Intel 和 Apple Silicon（ARM64）版本。

macOS App 使用 ad-hoc 签名，但未经 Apple 公证。请先将 `GPM.app` 拖入 `/Applications` 再打开。如果 macOS 阻止首次启动，请进入 **系统设置 -> 隐私与安全性** 并选择 **仍要打开**。如果该控件不可用，仅对从本项目官方 Release 下载的 App 执行：

