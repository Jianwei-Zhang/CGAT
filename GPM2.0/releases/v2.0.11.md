# GPM v2.0.11

## English

### Server

#### Improvements
- Generate smaller, independently regenerable reports by sharing embedded data and showing compact audit previews, while preserving complete events and original audit outputs.
- Include the staged GRT workflow, batched alignment scheduling and shared-cache safeguards in the standalone Linux source package.

#### Fixes
- Correct Step2 gapless-event coordinates, zero-length replacement metadata and terminal-deletion anchors (October 21). Independent Step2/Step3 stages and strict validation remain in place.

The October 21 Server-source refresh does not rebuild App installers or migrate existing runs.

### App

#### Improvements
- Import large delivery packages faster with native extraction, shared worker settings, streaming PAF processing and leaner indexes. All Final Path, length and checksum checks remain enabled.
- Keep archive picking and drag and drop consistent, with editable recommended names, clearer progress, cancellation and failed-project indicators.
- Improve Preview reference placement, grouped-fragment dragging and Assembly viewport preservation.

#### Fixes
- Same-version installer updates keep FASTA parsing and hashing in the optimized backend, prevent accidental import-dialog dismissal during text selection or IME cancellation, and stop Project Export gap labels from overlapping.

### Downloads

Windows x64 (`win-x86`) / ARM64; macOS Intel / Apple Silicon (ARM64). Linux Server source: `GPM_Server_2.0.11_source.tar.gz`.

No example delivery package was attached to this Release.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

#### 改进
- 共享报告内嵌数据并使用精简审计预览，减少报告体积；保留完整事件与原始审计输出，支持独立重新生成报告。
- 独立 Linux 源码包包含分阶段 GRT 流程、批量比对调度和共享缓存保护。

#### 修复
- 修正 Step2 无 GAP 事件坐标、零长度替换元数据及末端删除锚点（10 月 21 日），保留独立 Step2/Step3 阶段与严格校验。

10 月 21 日的 Server 源码更新未重建 App 安装包，也不迁移已有运行结果。

### App

#### 改进
- 采用原生解压、共享并行设置、流式 PAF 处理与精简索引，加快大结果包导入；保留全部 Final Path、长度和摘要校验。
- 统一文件选择与拖放入口，提供可编辑的推荐名称，改善进度、取消和失败项目提示。
- 改善 Preview 参考定位、分组片段拖动及 Assembly 视口保留。

#### 修复
- 同版本安装包更新使 FASTA 解析和摘要计算持续使用优化后端，避免选择文本或取消输入法候选时误关导入弹窗，并修复 Project Export 的 Gap 标签重叠。

### 下载

提供 Windows x64（`win-x86`）/ARM64、macOS Intel/Apple Silicon（ARM64）安装包，以及 Linux Server 源码 `GPM_Server_2.0.11_source.tar.gz`。

本 Release 未附带示例交付包。

### macOS 首次启动
以下提示同时适用于 Intel 和 Apple Silicon（ARM64）版本。

macOS App 使用 ad-hoc 签名，但未经 Apple 公证。请先将 `GPM.app` 拖入 `/Applications` 再打开。如果 macOS 阻止首次启动，请进入 **系统设置 -> 隐私与安全性** 并选择 **仍要打开**。如果该控件不可用，仅对从本项目官方 Release 下载的 App 执行：

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```
