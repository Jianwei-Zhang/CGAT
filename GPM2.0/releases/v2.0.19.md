## English

### Server

- Publish the matching v2.0.19 Server source package and update installation/tool-update links. Server processing algorithms are unchanged from v2.0.18; annotation libraries, frozen provenance and resource-aware mapping remain available.

### App

- Manage multiple Local View tasks from a taskbar, open them in separate native windows, resize them, and optionally pin them above the Main window within the App without keeping them above other applications. Transfer contigs between Main View and the intended Local View window.
- Select and pin multiple Final Path source segments together, including modifier-assisted box selection. Use consistent hand navigation and selection gestures across assembly views, without native text selection interfering with source drags.
- Preview drag-to-path additions while preserving contig fragment ranges. Keep Local View reference orientation, contig scale and chromosome-scoped edits consistent, with clearer source and overview highlights.
- Export overview images with SVG as the default format and align exported preview styling with the App. Improve Main View drag previews by reusing Canvas rendering.
- Resize the project sidebar and use more consistent typography, menu labels and compact Local View controls.
- Persist Local View tasks separately from legacy view state. Opening an existing workspace migrates schema 7 or earlier to 8; back up workspaces before upgrading, because older Apps cannot be assumed to reopen migrated workspaces.

### Downloads

- Windows: x64 (`win-x86`) and ARM64 installers.
- macOS: Intel and Apple Silicon (ARM64) installers.
- Linux Server: `GPM_Server_2.0.19_source.tar.gz`.
- Test data: `test_data.zip`, preserved byte-for-byte from v2.0.18 and originally published with v2.0.10.
- Signed in-app updates are available through the CGAT docs update source. Users on v2.0.12 or earlier must first manually install a version that supports in-app updates.

### macOS first launch

This guidance applies to both Intel and Apple Silicon (ARM64) builds.

The macOS apps are ad-hoc signed but not Apple-notarized. Drag `GPM.app` to `/Applications` before opening it. If macOS blocks the first launch, open **System Settings -> Privacy & Security** and choose **Open Anyway**. If that control is unavailable, run the following command only for the app downloaded from this official Release:

```bash
xattr -dr com.apple.quarantine /Applications/GPM.app
```

## 中文

### Server

- 发布对应的 v2.0.19 Server 源码包，并更新安装及工具更新入口。Server 处理算法相对 v2.0.18 没有变化；继续提供注释库、冻结的来源信息和资源适配比对。

### App

- 通过任务栏管理多个 Local View 任务，在独立原生窗口中打开、调整大小，并可固定在 Main 窗口上方；置顶仅作用于 App 内，不会覆盖其他应用。支持在 Main View 与指定 Local View 窗口之间转移 contig。
- 支持批量选择和固定 Final Path 来源片段，包括配合修饰键框选；统一装配视图中的手形导航与选择手势，避免拖拽来源时触发原生文本选择。
- 拖入路径前预览新增内容，并保留 contig 片段范围；保持 Local View 参考方向、contig 比例及染色体范围内编辑的一致性，改善来源和概览高亮。
- 概览图片默认导出 SVG，导出预览样式与 App 保持一致；复用 Canvas 渲染改善 Main View 拖拽预览。
- 支持调整项目侧栏宽度，统一字体层级和菜单文案，精简 Local View 控件布局。
- Local View 任务独立于旧视图状态保存。打开已有工作区时将 schema 7 或更早版本迁移到 8；升级前请备份，不能假定旧 App 可以重新打开迁移后的工作区。

以下提示同时适用于 Intel 和 Apple Silicon（ARM64）版本。

