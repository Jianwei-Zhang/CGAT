## Gap correction / Gap 配色修正

预览与项目导出的 Gap 标记改用独立 `--gap-marker-fill`，在黑白主题下都保持白色，不再复用面板背景色。预览上方的 `GAP` 文本在浅色主题下为纯黑色、深色主题下为纯白色；标记内部文字保持深色以保证白底可读。长度、坐标、提示信息及既有重叠隐藏规则不变。
