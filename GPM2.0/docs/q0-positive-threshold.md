# Q0: stop supplementary mapping at supported decisions

`positive_threshold` is a versioned Q0 evidence profile for **new Server workspaces without reads QC**. Use `--q0-supplement-scope positive_threshold` when preparing a workspace. The generated evidence command uses `--supplement-scope positive_threshold`. This is not a resource override for resuming an existing run. `full` retains the existing search and acceptance rules.

The profile builds a provisional backbone from all verified initial alignments, including within-assembly matrices. It asks for weak placements or unsupported junctions, never for the sole purpose of excluding a hypothetical competitor. A strong placement is not permission for an exact cut. The ordinary selector still accounts for competing observed loci, only admits supported paired cuts, and can leave an unknown join. An assignment label alone cannot supply a chromosome with its first reference seed.

## Decision rule for implementation and review

Once existing evidence meets the threshold for **this source interval and this decision** (placement, keeping a gap, or an exact cut), stop looking for competitors for that decision. Apply the stop before queuing work. When reviewing an enumeration, scan, alignment or check, ask: **what could its result change about this decision?** If its only purpose is to show that no alternative exists, remove it. Reuse evidence already checked for the same decision rather than checking it again.

For example, if a selected placement has sufficient support at both ends, a secondary assignment alone must not put that interval back on the request list. A weak adjacent junction is a separate decision: request its unsupported ends, not the whole contig. Evidence sufficient to **leave a gap** does not authorize closing it. Keep checks that can actually invalidate a proposed result, such as counting the same source bases twice or cutting outside the paired alignment. Stopping the search is not a claim that competitors do not exist.

The first request uses the ordinary ranking rules but consumes only each winning path's slices and joins. It does not build missing-base inventories for alternatives or a report of rejected placements. A reference seed is not split just because a rival exists: if neither outer flank can fit the minimum disjoint tail, no tail search is needed. If a tail could qualify, one eligible chain proving continuity is enough to retain the seed. Before propagating coordinate cuts the draft coalesces only touching or overlapping spans of the same source pair, orientation and offset. The boundary cap, original evidence IDs and source-occupancy checks still apply. Preparation and publication use a separate, full selection; a first-request object is not acceptable as a final record.

If preliminary chromosome coverage exceeds the boundary budget, ambiguity alone can be checked one independent region at a time. Maps belong to the same region if their coordinates overlap or touch on either source, directly or through another map. Only the original evidence IDs proven ambiguous are excluded. The scorer still requires one complete chromosome model under the original budget; an oversized irreducible region or final model fails rather than yielding an empty request.

## Supplementary scopes

- **`base_only`**: no supplementary planner ran. The normal consumer must regenerate an empty request from the selected evidence. An empty omission list is not evidence of a full search.
- **`supported_after_discovery`**: whole-contig discovery supplied the last missing support. Completed maps are retained; later discovery rounds and candidate maps are not enumerated. The ordinary consumer must independently find no outstanding request.
- **`decision_frontier`**: complete query/target contexts that touch a request are kept. The final selection is recomputed. An omitted context intersecting a still-weak decision requires repair. A newly extended request needs no additional pass if both original planning phases completely accounted for their regional tasks and the omitted intervals on both axes are disjoint from it.
- **`full`**: if decisions cannot be localized or bounded repair cannot resolve the search scope, use full supplementary discovery. Invalid bytes, a wrong tool or policy, reads QC, or the absence of a trustworthy path are **not** accepted as successful Q0 construction.

For partial-source discovery, the frontier filters windows only after their reference targets have been resolved. If a window has no reference targets or exceeds the regional target budget, the planner instead selects its whole parent for native fallback. A localized request or a high count of omitted windows does not show that this fallback was avoided. The planning log identifies its reasons and largest parents; check the native task and its completion receipt for reuse. A cold regional fallback does not launch a whole-source map: the bounded profile records the matrix as unsearched; a strict run cannot certify complete discovery without the evidence.

The ordinary `metadata/grt_q0_evidence.json` is published only after the scope and data have been verified. The selection artifact records `supplement_acceptance`, including `alternatives_exhaustive: false`: it certifies the selected backbone under the stated rule, not the absence of unobserved alternatives. Existing source occupancy and interval-aware donor logic are unchanged. Counts of completed windows are not counts of fresh mapper launches; compare both mapper invocations and end-to-end elapsed time before switching a large active analysis.

For large matrices the threshold planner and its verified consumer retain validated hits in a compact in-memory form. Original PAF bytes and record identities are not rewritten. The full ordered CIGAR, optional tags, source geometry and provenance remain available. This reduces retained-input memory, not the number of requested comparisons by itself. On a retained window an old exact mapper result can still be verified and reprojected; a projection signed by a different validator is not accepted under the new validator's identity.

For ordinary whole-contig candidate maps, the query **and every target** are checked against the open source intervals. A target shared with a still-weak join keeps the entire original map, in both orientations supported by the mapper; neither targets nor evidence rows are trimmed. Independent maps may share a wave. Maps competing for the same source or chromosome wait: after each wave the planner reevaluates the ordinary selector with the new evidence before deciding which competitors to launch. Physical aliases are mapped once but retain their logical chromosome records. An inconclusive selection is not grounds to skip a map.

When it skips whole candidates, the catalog lists them under `supplement_scope.native_candidate_stops` with their original chromosome, queries and targets. The omitted interval inventory covers both axes. They are **not searched**, not zero-hit maps. The final reader checks the scope against the selected joins; if support changed, a full native pass can reuse valid mapping receipts. Supplying `--q0-supplement-scope full` keeps exhaustive discovery even when a threshold would pass. No existing workspace silently changes profile on resume.

After Q0 publication, `python3 GPM2.0/experiments/q0_native_work_audit.py WORKSPACE` audits a verified ready manifest and donor freeze. To compare an older run, pass `--tools` pointing to a trusted matching producer checkout. It separates logical requests, distinct completed maps (not necessarily fresh mapper launches), skipped candidates and PAF rows cited by the selected path or alternatives. Repeated queries with different target sets are reported separately, **not** treated as reusable. An uncited map is not proof the map was unnecessary.

**Sparse requests on an ordinary-size assembly.** When base evidence leaves a localized question, `positive_threshold` can use the existing regional mapper before resorting to whole chromosome batches. This route requires `asm10`, reference evidence for each requested source, at least 32 core windows of input sequence, and source intervals (including flanks for routing) occupying at most 1/16 of the input. These are cost estimates, not new acceptance thresholds. It checks both sides of a potential map and retains native fallback for unqualified footprints. Before candidate dispatch it can re-evaluate completed discovery maps: `candidate_threshold_request: []` means those maps answered every outstanding question, not that the competitors had no hits. The final reader independently rechecks that conclusion. A full fallback on an ordinary-size reference uses the ordinary native search. `full`, reads QC and existing large-reference routing do not opt into this new choice. Inspect `supplement_scope.routing` and the per-phase omission/completion counts in the audit; completed window counts are not fresh mapper invocations or measured speedups.

See the [conservative fast-route design](q0-conservative-fast-design.md) for the distinction between bounded search and equivalent reuse.
