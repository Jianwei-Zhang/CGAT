# Q0 连续主导准入与参考同位点约束

适用范围：跟踪分支生产 Q0 引擎。这里是科学选路策略变更，不是“全麦无损等价”的声明；
正式 Q0→LGZ 仍须通过整麦隔离验证。原始参考/配对 PAF 及已成功区域比对不因选路策略变更而重跑。

## 不以参考方向切碎 de novo contig

- 同染色体反向锚链不能成为 `foreign_barriers`，也不能独立切出被主方向携带的源区间翻面。
  内部和端部倒位都按此规则保留连续源序列；没有品种、染色体名称或 contig ID 特判。
- 只有跨染色体、独立共线、高 MAPQ、达到原规模和密度门槛的链可以切分源区间。
  默认末端支持至少10 kb；内部至少100 kb且至少源段长度1%；密度至少50%，与主链支持
  的重叠不超过异组链支持的10%。相同染色体的正反方向均不参与这个切口定义。
- 原单定位直接准入保留。连续准入保留100 kb主链/75%全局支持的保守通路；新增通路要求
  主链至少500 kb、相对最强竞争链至少10倍，且单竞争定位组的总支持不超过主链的25%。
  高 MAPQ最低支持及携带区间20%支持门槛仍生效；反向证据仍计入竞争，不因不切分而被隐去。
- 连续准入候选不再进入旧100 bp配对尾端裁切，避免已过跨染色体大链屏障的携带区间被二次碎切，
  或将 `continuous_reference` 降级成普通 `reference`；旧普通参考准入的尾端处理保持不变。
- 只用主方向实际共线锚点定位和计量参考覆盖。携带区间可以包含无锚点区或内部倒位，
  但这些碱基不能冒充额外参考覆盖；源总长、获选参考并集、切片数须分开报告。

## 同位点等价，而非任意旁系重复

- 只有仍可共享参考位点的覆盖原子才合并为同位点冗余。比较的是参考正向的**原子起点**，
  不是两个原子中各自碰巧有锚点的位置。
- 默认每个原子位置范围的 padding 为 **100,000 bp**；它不是两定位距离恰好100 kb的截断线。
- 通过整个分量传播共同可行范围。未知位置不构成拒绝同源证据的理由，但不能把两个远端
  已定位分量通过未知桥串成一个等价分量；内部锚点不一致时保守退为未知。
- 原始竞争命中完整参与配对块唯一性判断，再排除原生歧义证据。不得先删竞争者再重新
  准入本来不唯一的关系。最终重复、方向、源边界和跨染色体源坐标占用门禁不放宽。
- 草选路和正式选路使用同一精确紧凑分区；不能让两者的原子粒度差异改变位点约束结果。

## 参考有序骨架与精确索引

- 存在连续准入候选时，用完整参考包络的加权区间DP提出源长度优先骨架，再逐条通过
  原生 Join、精确评分和 duplicate 门禁；整提案失败时保留合法前缀，不做低收益碎切精化。
- 完整提案和前缀恢复都按 Join 的证据顺序优先尝试精确重叠/原组装 gap；仅当前一种
  连接过不了原精确评分/duplicate门禁时再尝试下一种，不能为了多携带源碱基而优先插入100 N。
- 若无法得到合法骨架，保留原选路器作为回退。旧冻结路径仅在真实几何仍可回放时作为
  同图保底；旧切片已被新规则移除时不得伪造 Join 或偷偷重新放回。隔离对照仍比较冻结
  路径的总覆盖和评分下界，并单列获选参考 gain/loss；不保证新路径是旧区间严格超集。
- 参考包络决定提案顺序，不生成不存在的序列或同源证据；未入选及未覆盖源区间继续报告。
- 精确区间索引加速锚点支持、源对候选相交和等价原子定位，保留证据顺序、实际相交和
  所有竞争记录，不以减少证据量换速度。按源对输出建图进度，避免长阶段无反馈。

## 入口与缓存身份

`continuous_reference` 同时是补证判断的参考根和可检查的定位锚点，不能只改选路器而让
`q0_threshold_questions` 把它误判成“无参考根”或无锚点。接头复核也读取同一类型。

AdmissionPolicy/PathPolicy、连续准入、位点约束、骨架、索引及相关调用入口的源码都绑定
到新的 selector identity。旧草选路、旧正式选路不能冒充新代产物；完成的原始比对证据仍
按各自来源和内容复用。同代正式选路交付缓存继续消除下游重复选路，不能禁用门禁强行续跑。

## 全麦22组隔离验证准备

用户已授权定向回归通过后运行22组隔离验证；不自动运行正式Q0/LGZ或更新正式工作区。

1. 新建私有验证 owner，绑定跟踪分支源码、100 kb政策和输入清单；不覆盖
   `q0-whole-local-maps.soHq9Z6J` 的冻结22组结果。重新提交时先核实实际队列与内存需求。
2. 沿用该冻结对照的输入次序和完整比对来源：4份已采用native矩阵、59,278份历史区域
   证据及15份后续局部证据（共59,293份regional）。不得为了快而只取三个试验染色体的
   source cohort；旧缓存缺少源对时只读已有完成PAF，不启动冷mapper或整段全库回退。
3. 三组的完整screened-anchor缓存可按源身份复用；早退空记录不能冒充所有染色体已筛完。
   新政策生成新的准入和路径缓存；每组写完整结果后落盘，并在最终汇总中核对全部22组。
4. 用生产入口检查所有组的参考根、草/正式策略一致性及补证清单，不再把独立诊断脚本的
   monkeypatch当成生产实现。原始输入只读、输出写隔离目录，禁用外部mapper调用。
5. 汇总每组准入/获选参考并集、源总长、切片数、最长片段、N50、gap、旧Q0冲突和
   gain/loss；同时检查21条主染色体、Un、全22组源坐标占用及source-backed gap占用。
6. 单列内部倒位源区间有没有被切出翻面、跨亚基因组疑似错放、长同源块被位点规则拒绝、
   未获选或无参考确认的部分。不能以较低冲突数自动替代这些检查，不能只看覆盖长度。
7. 通过整麦门槛后再决定正式Q0→LGZ续跑。此次不合master；通用引擎提交与现场脚本/
   回执分开提交，方便后续精选回迁。
