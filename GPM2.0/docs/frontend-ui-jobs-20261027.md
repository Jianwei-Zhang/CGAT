## 1、2：分型轨道与 Final Path 同步

### 已确认的行为边界

用户确认：“增删轨道后立即同步 Final Path 和按钮状态，但不自动把主路径覆盖为预计算结果”。

- 轨道新增或删除成功后，同步 Final Path 的相关显示及预计算路径按钮，不依赖切页、重载或额外点击。
- 新增分型轨道后，按分型状态隐藏“预计算路径”入口。
- 删除全部分型轨道后，恢复主路径上下文和适用的“预计算路径”入口。
- 恢复入口不等于执行恢复操作；不得因此自动以预计算结果覆盖用户主路径。
- 轨道删除所涉及的关联数据处理与“恢复预计算路径”是不同操作，不得混为一体。

### 待实现时核实的验收细节

- 按当前染色体作用域处理，不影响其他染色体的路径或轨道状态。
- 覆盖第一条轨道新增、非最后一条轨道删除、最后一条轨道删除，以及重新进入页面。
- 无可用预计算基线时，不显示无效入口；已处于预计算路径时，保留当前禁用语义。
- 创建或删除失败时，不提交虚假的成功状态；清理成功删除后失效的分型路径选择。
- 不通过整页重载实现联动；不重置无关视口或用户编辑。

## 6：主视图工具区重排（已确认，未实现）

用户追问：能否让“预计算结果”“分型轨道”和其他控件同级，参与重排对齐？

用户确认：标题独立，所有工具控件同级整组换行。取消这两个操作独占标题右侧的特殊布局，让全部工具控件进入同一个可换行容器。

- “主视图”标题保持独立标题行，不参与参数控件布局。
- 标记显示、辅助数据集选择、Contig 长度、比对长度、一致性、历史操作、预计算结果、分型轨道作为同级控件组参与布局。
- 同级是指布局层级一致，不代表把复选控件和按钮改成相同语义，也不强制相同宽度。
- 一组包含其标签、输入/选择框、单位及紧密关联操作；组内不拆行。
- 统一控件高度与组内垂直对齐，各行左对齐，固定间距；保持固定 DOM/阅读顺序。
- 优先用 CSS Flex 换行，不按测量结果反复切换 Flex/Grid 或搬动控件。
- 控件优先按内容占宽，不平均拉伸；超长名称在控件内部截断，不挤出容器。
- 进入下一行时允许工具区高度增加，但不允许临界宽度反复来回跳动。
- 尺寸变化、语言切换不重建页面，不重置焦点、菜单、选择或视口。
- 后续验收覆盖中英文、长数据集名称及临界宽度；组内仍超宽时的最小窗口适配需在实现前明确。

本方案已获用户确认，替代此前“标题右侧保留预计算结果和分型轨道、参数单独换行”的建议。

## 5：术语与命名（原则及示例已确认，未实现）

### 用户提出的大小写规则

- 大标题使用每词首字母大写，例如 `Main View`。
- 小标题、字段标签使用首词首字母大写，例如 `Alignment length`。
- 系统提供的选项显示文本使用每词首字母大写。
- 专业名称和单位保留标准形式，例如 `GRT`、`FASTA`、`bp`、`Mb`。
- 数据集名、项目名、Contig ID、文件路径等真实数据保持原值；不修改内部字段或枚举值。

### 已确认：去冗余、保含义

用户提出：`Auxiliary ds ctg len` 中能否直接不要 `ds`？

用户确认：不是机械地将全部 `ds` 展开为 `Dataset`，而是按标签实际指代消除冗余；采用下列示例措辞。

| 场景 | 已确认英文 | 已确认中文 |
| --- | --- | --- |
| 辅助 Contig 长度字段 | Auxiliary contig length (bp) | 辅助组装 Contig 长度 (bp) |
| 辅助数据集选择字段 | Auxiliary dataset | 辅助数据集 |
| 主数据集成员区域的大标题 | Primary Dataset Members | 主数据集成员 |

- 长度字段的对象是 Contig，因此可省略 `ds`；`ctg`、`len` 展开为 `contig`、`length`。
- 真正选择数据集或标识数据集成员的场景仍保留 `dataset / 数据集`，避免丢失对象含义。
- 长度字段采用“辅助组装 Contig 长度 (bp)”，不自行进一步简写；其余全 App 词条按上述原则整理，含义有歧义时再确认。
