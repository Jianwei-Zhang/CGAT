## Go/No-Go 执行标准

以下数值是本次工程审查触发线，不是通用生物学精度保证，也不是与全库无损等价声明。
任何结构或内容硬错误直接 No-Go，不能被总体指标掩盖。

1. **完整性硬门槛**：22 组都有闭合的结果/回执；21 条主染色体均有非空可信获选骨架，
   既有定位/序列/占用/连接门槛全部通过；Un 单独报告，不代替缺失主染色体。
2. **相对同一冻结基线的复核线**：参考覆盖按区间并集合计，不能用 PAF 行数或 source bp
   冒充；全局覆盖下降 >1% 或任何主染色体下降 >2%，gap 总碱基或数量增加 >5%，
   或未放置源碱基占比增加 >1 个百分点，均先暂停查原因。基线为 0 的项目直接审阅新增项。
   未放置长度按 source-qualified 原始来源区间并集计算，避免双重计数。低于这些线也不豁免第3条。
3. **结构风险硬门槛**：对路径来源、方向、切点、连接发生变化的组，先列出全部变化；
   检查其中涉及 A/B/D 高同源定位切换的接头，核对两侧已有支持和具体竞争证据。
   发现不能解释的跨亚基因组错接/方向冲突/源重复占用就 No-Go。LGZ 补洞不作为错拼兜底承诺。
4. **放行对象**：上述通过只表示允许正式 Q0→LGZ 受控运行，不表示全流程交付已经验收。
   正式运行仍须产生 Q0 FASTA/来源清单，并观察 LGZ 的真实内存、耗时、连接与补洞结果。

已排队的22组比较脚本未输出全部覆盖/未放置指标时，直接从封存路径与来源/定位表补算只读
