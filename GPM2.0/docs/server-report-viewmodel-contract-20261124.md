# CGAT Server report ViewModel v1 · frontend handoff (2026-11-24)

Presentation design: [Final Path report narrative and acceptance criteria (2026-11-25, 中文)](server-report-final-path-design-20261125.md). This v1 contract describes existing data, not the implementation status of the new cards.

`server/tools/report_overview_data.py::build_overview_view_model(root, batch=None, *, mode=None, verify_content=False, generated_at=None) -> dict` is the read-only boundary. Add `server/tools` to the Python import path. It does not start tools, publish, repair inputs or save a report. An online writer supplies its own batch; an offline reader identifies the current completion by **automatic overview digest**, validates the batch hash and its comparison file hashes, and never infers ownership from a directory timestamp. Missing LGZ data are diagnostic, not a new zero measurement. A self-contradictory layout or sealed comparison is an error; do not silently present a different generation.

## Renderers (no locks, receipt writes or workspace discovery in templates)

| Module | Interface |
|---|---|
| `render_overview_report.py` | `render_overview(vm) -> str`, automatic HTML shell with exactly one closing `</main>`. |
| `render_refinement_report.py` | `render_tool_pages(summary, provenance, final, assets, *, page_size=200)` yields `(report_relative_name, html)` one page at a time (`report.html`, `native.html`, `gaps/NNNNNN.html`, optional `sources-NNNN.html`); `render_failure(summary) -> str`. Preserve original Gap IDs, existing anchor targets, the isolated native visualizer and asset links. `summary.json` and `final_path.json` are report-local; provenance is the matching `binding.provenance_sha256` object. |
| `render_manual_report.py` | `render_batch(summary, links) -> str`; `render_overview(entries) -> str` **fragment**; `render_landing(section, lgz_href) -> str`. Each entry is `{summary, links: {label: href}}`. |
| `render_server_report.py` | `render(root: Path) -> Path` reads only LGZ report-local JSON; copied verbatim as the standalone `01_lgz/render_report.py`. `bounded_id_projection(value)` is HTML-only: `evidence_ids`, `usage_ids` and `final_path_segment_ids` longer than 10 become `{count, preview}`. Never run that projection on the audit writer. |

**Mutable manual content belongs only in the marked overlay.** `refine_report.py` alone owns `SECTION_START`, `SECTION_END`, insertion immediately before `</main>`, and `automatic_overview_digest`. Do not embed a second copy of `manual_summary`, manual links or the entire VM as JSON outside the overlay on the live overview. Manual import has no automatic publication authority. Separate export JSON is not a scientific receipt. The renderer's own source SHA is part of successful/failed automatic tool-report bindings and delivery generation; do not update previously published manifests in place. Each detached tool directory has a separate `cgat.detached-tool-report.v1` manifest (source report manifest SHA and actual output file hashes), not a tool publication receipt. New portable tool reports omit read paths from recipes and leave attachments containing them on the server (`server_only_private_reads`).

## JSON record

The five top-level objects below are always present. `?` = optional/nullable; `[]` is an array; count/coordinate/byte fields are nonnegative integers unless indicated. A missing measurement is unavailable, not zero. `href`s are unescaped, POSIX, relative to `report.html`; templates must escape **both** attribute and text contexts, and must not build links from user-controlled path fragments. `--out-dir` strips external links while retaining workspace-relative display paths.

* **`meta`**: `schema_version="cgat.report-overview.v1"`, `workspace_name:string`, `workspace_layout:{version:1|2,schema:string,result_prefix:string?,project_delivery:bool}`, `batch_id:string?` (32 hex), `batch_status:string?`, `exit_code:int?`, `generated_at:ISO timestamp` (explicit snapshot time, or batch/LGZ end where recorded, otherwise build time), `mode:full_pipeline|lgz_only|lgz_failed|manual_only`.
* **`lgz_summary`**: `status?, run_id?, ended_at?, href?, diagnostics:string[]`, `failure_reasons?:string[]`. The schema/run identity is checked for inputs, numbered steps, LGZ child stages and final summary. No raw command, raw event, ID list, sequence, absolute read path or reconciled-event object goes into this model.
  * `inputs.reference[]`, `inputs.assemblies[]`: `{name,role,stats}`. Stats select `sequence_count,length_bp,n50_bp,n_bp,gap_count,gap_bp` when recorded; LGZ FASTA statistics count N runs ≥100 bp, **not** every original refinement Gap. `typed_reads[]:{technology,file_count}`; older snapshots may lack typed reads. `annotations` maps `telomere_rules`/`centromere_reference` to `{configured?,row_count}`. Configured means configured, not detected.
  * `assignment:{min_coverage_percent,groups}`: configured threshold from the same run’s recorded package metadata (null if unknown). `groups:null` means complete membership unavailable, distinct from an observed empty table. Groups follow reference order with `chr,member_count,sources:[{dataset,members:[{name,multi}]}]`; multi-group identity is `(dataset, name)`, never the display name alone. The 01/02 cards do not read the workspace or infer group membership from q0.
  * `funnel` optionally contains `input_contigs`, `reference_aligned_contigs` (only when all assembly datasets have reference measurements), `assigned_unique_contigs`, `unassigned_contigs`. Datasets can overlap biologically: sums count input records, not unique biological loci.
  * `q0_scene`: complete ordered ref/q0 tracks in 0-based half-open coordinates, or null when unverifiable. A matching SHA-256 binds the frozen selection to this run. Bands are equal-length source/reference anchors clipped to the selected slice on its strand, not inferred q0 alignments. A complete captured legacy segment table can supply layout only (no ribbons, unknown gap origin). Positioned reference gaps require run-bound FASTA statistics; older missing positions are not zero gaps.
  * `q0`: numeric producer summary (`selected_chromosomes`, `not_constructed_chromosomes`, `selected_datasets`, `selected_source_bp`, `input_gap_joins`, `unknown_joins`, `sequence_overlap_joins`, corresponding N bp when recorded). `source_bp:{dataset:int}`, `source_rows_truncated:bool`; older source-composition previews can provide only partial contributions. `donor_freeze?:{donor_sets?,donor_members?}` counts report table rows, not independent closures.
  * `sequence_versions:{q0|q1|q2|q3|q4:stats}`; q4 is historical, never relabel as q3. `stage_events:{stage:{event_count?,by_status,by_action}}`, `process_summary?`, `final_event_summary?` (same structure); `outcome` contains recorded numeric final outcomes. Process accepts are not cumulative final closures.
  * `timing:{units,stages,parallel_groups}`. A unit has `unit,stage,output_directory?,status,execution,elapsed_seconds?:number,started_at?,ended_at?,exit_code?:string,parallel_group?,reason?`. `execution=computed|cache_reused|frozen_original_lgz|failed|pending`; interrupted is explicit in `status`. Group/stage rows: `id,unit_count,measured_unit_count,unit_seconds?:number,observed_span_seconds?:number,statuses:{status:n},executions:{method:n}`. Unit-seconds can overlap; observed span is calculated from recorded clocks, not their sum.
  * `chromosomes[]:{chromosome,length_bp,source_bp,segment_count,segment_kinds,segments:[{start,end,kind,source?,patch:bool}],remaining_gap_count?,telomeres:{end:status},centromere_marker_count,centromere_markers:[{q4_start,q4_end}]}`. Segment coordinates are 0-based half-open. Centromere coordinates from the original projection are **1-based inclusive**, regardless of final q version. Each preview ≤200 per chromosome; aggregate counts describe all segments/markers, not the preview.
* **`refinement_summary`**: `comparison_href?`, `best_tool:null`, `biological_accuracy_validated:false`; `tools[]:{tool,status,run_id?,phase?,reason?,result_reused,native_reused,native_executed?:bool,native_status?:string,counts?,accepted_edit_count?,retained_flank_count?,remaining_gap_count?,publication_verified,report_href?,links:{label:href?}}`. `counts` maps closed/partial/unfilled/rejected to counts. Failed/not-attempted counts are unavailable, not a successful zero. Original flanks retained are not an accepted native replacement. Published tool reports require the matching batch transaction, run and report manifest.
  * `by_chromosome[]:{chromosome,original_gap_count,tools:{tool:{original_gap_count,closed,partial,unfilled,rejected,not_evaluated}}}` aggregates the **entire** original-gap matrix; `tool_failed` etc. contribute to `not_evaluated`, not `unfilled`. Never rank tools on this data.
  * `gap_matrix:{total_gap_count:int?,preview_count,truncated:bool,source:string?,full_tsv_href?,coordinate_system:"lgz_0_based_half_open",rows:[{gap_id,chromosome,start,end,tools:{tool:status}}]}`. Keep original TSV order and match `chromosome` to the LGZ overview; join on `gap_id`, not native per-tool numbers. `rows` ≤ `REPORT_PREVIEW_ROWS=200`. No comparison means `total_gap_count:null`, not an invented empty batch.
* **`manual_summary.batches[]`**: `batch_sha256,report_status:pending_app_import|no_patch,completed_at?,result_counts:{status:n},report_href?,summary_relpath,patch_relpath,delivery_sha256?,publication_verified:bool,reads:[{technology,sha256}]`. Only the digest and technology are public; no App import receipt is inferred.
* **`result_paths`**:
  * `quick_pickup[]:{category:fasta|catalog|app|auto_patch|manual_patch|diagnostics,label_key,relpath?,href?,exists,status,size_bytes?,sha256?,sha256_short?,checksum_source:content|receipt|null,publication_verified:bool}`. `status=not_generated|not_enabled|observed|historical|changed|published|external_not_inspected`. An observed file is not necessarily committed in this invocation. `publication_verified` denotes matched publication provenance; with `checksum_source=receipt` it is **not** a fresh checksum of the file. Receipt-only reads check current existence, archive byte size and catalog ownership without reopening big FASTAs/archives. Changed content (when checked) has no pickup link. Detached copies have no workspace links. A legacy external target is never linked outside the workspace.
  * `directory_tree[]:{path,kind:directory|file,role_key,stage_ref,exists,file_count,protected,naming_rules:string[],child_count,children:node[]}`. Top-level roles follow the declared layout; numbered project/job/earlier numbered/unmarked workspaces do not borrow names from one another. Real directories through the third level; file counts include nested regular files, never symlink targets. Child lists preview up to 200 siblings. `child_count` gives the untruncated count at expanded levels. `maintenance:{never_delete_runtime:true,preview_command:string?}`. `compact_refinement.py` preview is informational, never invoked by reporting.

## Lifecycle / example data

Preparation does **not** create the workflow overview. An incomplete numbered `run_all` with no existing overview gets a diagnostic overview. Refinement writes the current batch and immutable comparison; under the live publishing lock the post-delivery refresh checks previous hashes before replacing only the automatic overview digest in the completion. A durable before/after intent records interrupted replacements; other completion fields are not refreshed to hide drift. App packages continue to embed `01_lgz/`, never the workspace overview or its private runtime.

From `GPM2.0/`, `python3 -B server/tests/report_scenarios_fixture.py /tmp/new-cgat-report-fixtures` writes workspace directories and side-by-side `<scenario>.json` VMs. Scenarios: `success`, `lgz_only`, `partial`, `manual`, `large` (21 chromosomes × 16 original gaps), `legacy_v1`, `v2_job`, `v2_legacy`. Fixtures are interface data with synthetic placeholder archives, not App import, performance or genome validation datasets. Use a new/empty destination. See `server/REPORT.md` for read-only regeneration.

* LGZ capture and portable projection: `server_report.py`, `server_report_io.py`, `server_report_collect.py`, `server_report_q0.py`, `render_server_report.py`.

The first three call the replaceable `render_overview_report.py`, `render_refinement_report.py`, and `render_manual_report.py` templates; they still own validation and atomic writes. `regenerate_reports.py` orchestrates only report regeneration.

After changing templates, run `python3 -B GPM2.0/experiments/long_query_alignment/sync_server_runtime.py --write`, then without `--write` to verify. These inventories bind file content; report changes do not alter Q0 scheduling.
* Tests and documentation: `server/tests/report_scenarios_fixture.py`, `server/tests/test_report_overview_data.py`, `server/REPORT.md`, and this document. All tools above live under `GPM2.0/server/tools/`.
